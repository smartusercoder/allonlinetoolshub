# Tool Catalog Plan

## Naming rules
- **Category names:** Title Case, singular (e.g., "Finance", "Media").
- **Subcategory names:** Title Case, singular, use "&" only for tightly coupled pairs (e.g., "Image & Design").
- **Tool names:** Title Case, action + object pattern when possible (e.g., "PDF Merge", "CSV Cleaner").
- **Difficulty scale:** 1 (easy) to 5 (hard).
- **Demand estimates:** Monthly search volume estimates in thousands (k).

## Overlap pruning and dynamic-mode merges
- **PDF Studio:** Merge, Split, Compress, PDF-to-Image, Image-to-PDF, Word-to-PDF, PDF-to-Word as modes within one PDF workspace.
- **Image Converter Studio:** PNG↔JPG, WebP conversion, and Image Resizer share a single UI with output format and size panels.
- **Media Optimizer:** Image Compressor and Video Compressor share a unified compression UI with media-type switch.
- **Developer Inspector:** JSON/XML validators, formatters, and Base64/Hash/JWT tools share a single pane with tabs.
- **Finance Calculators:** Loan, Mortgage, Compound Interest, ROI, Tax, and Sales Tax share a calculator shell with mode selection.
- **Education Writing Suite:** Grammar, Plagiarism, and Citation tools share input/output and report panels.
